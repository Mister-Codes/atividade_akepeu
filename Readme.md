Este projeto foi desenvolvido como parte de uma atividade escolar orientada pelo professor Akepeu, durante as aulas de Programação e Algoritmos. Seu objetivo é colocar em prática os conhecimentos adquiridos sobre Git e GitHub, explorando suas funcionalidades e aprendendo a utilizar ferramentas de controle de versão para organizar, registrar e compartilhar alterações em projetos. O principal fonte de estudos veio do canal Rafaella Ballerini, referente ao seu vídeo "COMO USAR GIT E GITHUB NA PRÁTICA! - desde o primeiro commit até o pull request! 2/2".
